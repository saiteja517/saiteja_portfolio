# Saiteja Portfolio — Netlify Ready

Files:
- `index.html` — portfolio website
- `style.css` — responsive styling

## Before publishing
Contact links are already configured in `index.html`.

## Netlify
1. Put these files in a GitHub repository.
2. In Netlify, import the GitHub repository.
3. Build command: leave blank.
4. Publish directory: `.`
5. Deploy.

The site is a static HTML/CSS portfolio, so no server or API key is required.
